# Vladimir1 — тестовый сайт

Многоязычный статический сайт с 11 языковыми версиями. Актуальные файлы сайта находятся в `site/`. Тестовый адрес — https://ural66-design.github.io/trading-without-tie/.

Редактируйте файлы в `site/`, проверяйте страницы и ссылки перед коммитом. Сборка не нужна. При изменении `site/` или workflow в `main` GitHub Actions публикует содержимое `site/` в корень тестового сайта. Проверьте результат в Actions и откройте изменённые страницы.

Маршруты `pt-BR/` и `pt-br/` различаются регистром. Для работы с обоими каталогами используйте файловую систему с учётом регистра.

При ошибке отмените проблемный коммит через `git revert` и проверьте новую публикацию. Для полного отката перехода сначала отмените коммит очистки, затем коммит перехода и отправьте оба отката вместе.
