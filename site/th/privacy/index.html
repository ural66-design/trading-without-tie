นโยบายความเป็นส่วนตัว

ข้อกำหนดทั่วไป

นโยบายความเป็นส่วนตัวนี้กำหนดวิธีประมวลผลข้อมูลที่เกี่ยวข้องกับการใช้ Vladimir1.com รวมถึง T-Capital และ Fast Money Bot

การใช้เว็บไซต์

Vladimir1.com ไม่มีการลงทะเบียนผู้เข้าชม การสร้างบัญชีส่วนตัว หรือการให้ข้อมูลส่วนบุคคลผ่านแบบฟอร์มในเว็บไซต์

เว็บไซต์ไม่ใช้พิกเซลโฆษณาหรือระบบบุคคลที่สามเพื่อติดตามพฤติกรรมผู้เข้าชม

ภาษาที่เลือกและความคืบหน้าในคู่มือจะบันทึกโดยตรงในเบราว์เซอร์ของผู้ใช้ผ่านพื้นที่จัดเก็บข้อมูลในเครื่อง

การตั้งค่าเหล่านี้ไม่ถูกส่งไปยังฐานข้อมูลของเว็บไซต์ และผู้ใช้สามารถลบได้ด้วยเครื่องมือของเบราว์เซอร์

อีเมล

เมื่อติดต่อ support@vladimir1.com อาจมีการประมวลผลอีเมลผู้ส่ง เนื้อหาข้อความ และข้อมูลที่ให้โดยสมัครใจ

ข้อมูลที่ได้รับใช้เพื่อพิจารณาคำถามหรือคำขอและเตรียมคำตอบ

ฐานทางกฎหมายของการประมวลผลนี้อาจเป็นการดำเนินประโยชน์โดยชอบด้วยกฎหมายเกี่ยวกับการพิจารณาคำขอที่ได้รับ โดยเคารพสิทธิและเสรีภาพของเจ้าของข้อมูลส่วนบุคคล

การติดต่อไม่ถูกเผยแพร่ ไม่ใช้ส่งโฆษณา และไม่ส่งให้องค์กรบุคคลที่สามเพื่อการตลาด

การรับและเก็บการติดต่อทางอิเล็กทรอนิกส์ดำเนินการผ่านโครงสร้างพื้นฐานอีเมล

อย่าส่งข้อมูลหนังสือเดินทาง รหัสผ่าน ข้อมูลชำระเงิน เลขบัญชีโบรกเกอร์ หรือข้อมูลการเงินที่เป็นความลับอื่นไปยังฝ่ายสนับสนุน

เรื่องบัญชีโบรกเกอร์และธุรกรรมทางการเงินควรติดต่อฝ่ายสนับสนุนของโบรกเกอร์นั้นโดยตรง

การติดต่อจะถูกเก็บไว้ตามระยะเวลาที่จำเป็นต่อการพิจารณาคำขอ หรือเมื่อมีเหตุทางกฎหมายอื่นที่กำหนดให้เก็บ

ข้อมูลทางเทคนิค

เมื่อเข้าชมเว็บไซต์ ผู้ให้บริการโฮสติ้งและโครงสร้างพื้นฐานทางเทคนิคอาจประมวลผลที่อยู่ IP ข้อมูลเบราว์เซอร์ อุปกรณ์ และพารามิเตอร์คำขอทางเทคนิคที่จำเป็นในการเข้าถึงหน้าเว็บ

Vladimir1.com ไม่ใช้ข้อมูลดังกล่าวเพื่อสร้างโปรไฟล์โฆษณาของผู้เข้าชมด้วยตนเอง

แหล่งข้อมูลบุคคลที่สาม

เมื่อเปิดลิงก์ไปยังแหล่งข้อมูลบุคคลที่สาม การประมวลผลข้อมูลเป็นไปตามเงื่อนไขและนโยบายของบริการนั้น

Vladimir1.com ไม่กำหนดวิธีประมวลผลข้อมูลส่วนบุคคลขององค์กรบุคคลที่สามที่เป็นอิสระ

บอต Telegram Fast Money Bot

เพื่อให้บอต Telegram Fast Money Bot ทำงาน ฐานข้อมูลของบอตจะเก็บเฉพาะรหัสระบุผู้ใช้ Telegram (Telegram ID)

ฐานข้อมูลของบอตไม่เก็บชื่อผู้ใช้ ชื่อเล่น หมายเลขโทรศัพท์ หรือเนื้อหาข้อความ

การประมวลผลคำถามของผู้ใช้ใช้ระบบตอบคำถามที่พบบ่อยอัตโนมัติและเทคโนโลยีปัญญาประดิษฐ์ผ่าน OpenAI API

เมื่อสร้างคำตอบด้วยปัญญาประดิษฐ์ เนื้อหาคำขอที่เกี่ยวข้องจะถูกส่งผ่าน OpenAI API เพื่อประมวลผลและสร้างคำตอบ

ผู้ใช้ยังสามารถติดต่อฝ่ายสนับสนุนโดยตรงผ่าน Telegram ได้

การประมวลผลข้อมูลโดยแพลตฟอร์ม Telegram เองอยู่ภายใต้เงื่อนไขและนโยบายความเป็นส่วนตัวของบริการนั้น

การปกป้องข้อมูล

เมื่อประมวลผลข้อมูลที่ได้รับ จะใช้มาตรการด้านองค์กรและเทคนิคเพื่อป้องกันการเข้าถึง เปลี่ยนแปลง เผยแพร่ หรือทำลายข้อมูลโดยมิชอบ

คำขอเกี่ยวกับข้อมูลส่วนบุคคล

คำขอข้อมูลเกี่ยวกับการประมวลผลข้อมูลส่วนบุคคล การแก้ไข การจำกัดการประมวลผล หรือการลบ จะได้รับการพิจารณาตามกฎหมายที่ใช้บังคับ
