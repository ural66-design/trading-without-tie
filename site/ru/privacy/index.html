Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки информации, связанной с использованием Vladimir1.com, включая направления T-Capital и Fast Money Bot.

Использование сайта

Vladimir1.com не предусматривает регистрацию посетителей, создание личных кабинетов и предоставление персональных данных через встроенные формы.

Сайт не использует рекламные пиксели и сторонние системы поведенческого отслеживания посетителей.

Выбранный язык интерфейса и прогресс прохождения инструкций сохраняются непосредственно в браузере пользователя посредством локального хранилища.

Указанные настройки не передаются в собственную базу данных сайта и могут быть удалены пользователем средствами браузера.

Электронная почта

При обращении на support@vladimir1.com могут обрабатываться адрес электронной почты отправителя, содержание сообщения и добровольно предоставленные сведения.

Полученная информация используется для рассмотрения обращения и подготовки ответа.

Правовым основанием такой обработки может являться осуществление законных интересов, связанных с рассмотрением поступивших обращений, при условии соблюдения прав и свобод субъекта персональных данных.

Переписка не публикуется, не используется для рекламных рассылок и не передаётся сторонним организациям в маркетинговых целях.

Приём и хранение электронной корреспонденции осуществляются с использованием почтовой инфраструктуры.

Не следует направлять на адрес поддержки паспортные данные, пароли, платёжные реквизиты, номера брокерских счетов и иную конфиденциальную финансовую информацию.

По вопросам брокерских счетов и финансовых операций необходимо обращаться непосредственно в службу поддержки соответствующего брокера.

Переписка хранится в течение периода, необходимого для рассмотрения обращения, либо при наличии иных предусмотренных законодательством оснований для её сохранения.

Техническая информация

При посещении сайта поставщики хостинга и технической инфраструктуры могут обрабатывать IP-адрес, сведения о браузере, устройстве и параметры технических запросов, необходимые для обеспечения доступа к страницам.

Указанная информация не используется Vladimir1.com для самостоятельного формирования рекламных профилей посетителей.

Сторонние ресурсы

При переходе по ссылкам на сторонние ресурсы обработка информации осуществляется в соответствии с условиями и политиками соответствующих сервисов.

Vladimir1.com не определяет порядок обработки персональных данных независимыми сторонними организациями.

Telegram-бот Fast Money Bot

Для функционирования Telegram-бота Fast Money Bot в его собственной базе данных сохраняются исключительно идентификаторы пользователей Telegram (Telegram ID).

Имена пользователей, никнеймы, номера телефонов и содержание сообщений в собственной базе данных бота не сохраняются.

Для обработки обращений пользователей применяются автоматизированная система ответов на часто задаваемые вопросы и технологии искусственного интеллекта с использованием OpenAI API.

При формировании ответов с использованием искусственного интеллекта содержание соответствующих запросов передаётся через OpenAI API для обработки и формирования ответа.

Пользователям также предоставляется возможность непосредственного обращения в службу поддержки посредством Telegram.

Обработка информации непосредственно платформой Telegram регулируется условиями и политикой конфиденциальности соответствующего сервиса.
