# Оформление главной страницы Vladimir1.com

1. Положите изображения темы в `site/themes/имя-темы/`. Пути в настройках задаются от `site/`. Чтобы фон формировался из аватара, укажите `"background": null`.
2. Возьмите `tools/theme/sea.json` как образец. Сохраните отдельный файл настроек для каждой темы, которую хотите повторно использовать. Укажите имя, версию, пути, `accent` и нужные цвета главной страницы. Цвет цифры 1 берётся из `accent` для всех вариантов V1.
3. Из корня репозитория выполните `node tools/theme/apply.cjs путь/к/настройкам.json`. Скрипт использует Node.js и Sharp, как генератор OG-баннеров. Для повторного применения текущих настроек можно отредактировать `site/themes/active.json` и запустить команду без аргумента.
4. Проверьте главную страницу и опубликуйте изменения текущим процессом GitHub Pages. Скрипт обновляет статические ресурсы и версию в их адресах. Уже установленное приложение получит новый значок по расписанию браузера или ОС.

Чтобы вернуться к морской теме, выполните `node tools/theme/apply.cjs tools/theme/sea.json`.
