# Vladimir1.com

Многоязычный статический сайт с 11 языковыми версиями. Актуальные файлы сайта находятся в `site/`. Основной адрес — https://www.vladimir1.com/.

Редактируйте файлы в `site/`, проверяйте страницы и ссылки перед коммитом. Сборка не нужна. При изменении `site/` или workflow в `main` GitHub Actions публикует содержимое `site/` в корень сайта. Проверьте результат в Actions и откройте изменённые страницы.

Маршруты `pt-BR/` и `pt-br/` различаются регистром. Для работы с обоими каталогами используйте файловую систему с учётом регистра.

При ошибке отмените проблемный коммит через `git revert` и проверьте новую публикацию. Для полного отката перехода сначала отмените коммит очистки, затем коммит перехода и отправьте оба отката вместе.
