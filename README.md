# Трейдинг без галстука

Первая страница личного сайта Владимира: трейдинг, автоматизация торговли и путешествия.

Адаптивная страница на HTML, CSS и JavaScript, без сборки и внешних зависимостей.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`.

## Ссылки

Адреса кнопок находятся в `links.js`. YouTube и Instagram подключены. Разделы «Трейдинг» и «Торговые роботы» готовятся.

## Оформление

Кнопка с палитрой сверху слева переключает Море / Зима / Весна. Выбор сохраняется на устройстве посетителя. Основная тема по умолчанию задаётся атрибутом `data-theme="sea"` у `<html>` в index.html; значения: sea, winter, spring. Новая настройка по умолчанию действует для посетителей, которые ещё не выбрали свою тему. Стили и декор: themes.css; переключение: themes.js. Без библиотек, анимации, дополнительных фотографий или сетевых запросов к сторонним сервисам.

Меню RU — только визуальный макет. Переводов и переходов пока нет. При добавлении языковых страниц каждой нужен собственный статический og:title, og:description и баннер на её языке. Сейчас страница русскоязычная, баннер social-preview-ru-v2.jpg. Сезонная тема посетителя не меняет общий баннер ссылки.
